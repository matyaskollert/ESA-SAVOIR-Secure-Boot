This project implements a simplified ECSS-\/inspired packet protocol for uploading firmware to STM32\+F4 microcontrollers via UART. The protocol is based on ECSS-\/\+E-\/\+ST-\/70-\/41C telemetry and telecommand packet structures, adapted for a proof-\/of-\/concept implementation.\hypertarget{md__e_c_s_s___p_r_o_t_o_c_o_l_autotoc_md1}{}\doxysection{\texorpdfstring{Protocol Overview}{Protocol Overview}}\label{md__e_c_s_s___p_r_o_t_o_c_o_l_autotoc_md1}

\item This is a {\bfseries{simplified}} ECSS implementation for proof-\/of-\/concept
\item Full ECSS compliance includes additional features:\+
\begin{DoxyItemize}
\item CRC-\/16 or CRC-\/32 for data integrity
\item Secondary headers for timestamps and source IDs
\item Application ID (APID) for multiple services
\item More sophisticated error correction
\end{DoxyItemize}

\item Byte order:\+ Big-\/endian for header fields (network byte order)
