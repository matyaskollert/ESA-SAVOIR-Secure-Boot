This document describes the hardware-\/in-\/the-\/loop (HIL) test suite for the Boot Software (BSW) bootloader running on the STM32\+F439\+ZI (Nucleo-\/\+F439\+ZI board). Tests are implemented in Python using pytest and communicate with the board over UART (ECSS packet protocol) and SWD (STM32\+Cube\+Programmer CLI for flash/\+option-\/byte access).

\DoxyHorRuler{0}
\hypertarget{md__t_e_s_t___s_u_i_t_e___d_e_s_c_r_i_p_t_i_o_n_autotoc_md25}{}\doxysection{\texorpdfstring{Hardware and Flash Layout}{Hardware and Flash Layout}}\label{md__t_e_s_t___s_u_i_t_e___d_e_s_c_r_i_p_t_i_o_n_autotoc_md25}
The MCU uses STM32 dual-\/bank Flash. The relevant sectors are:\+


\begin{DoxyTable}{4}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Region  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Address  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Sector  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Role  \\
SLOT\+\_\+A (MAIN)  &0x08020000  &5  &Primary application image slot  \\
SLOT\+\_\+B (UPDATE)  &0x08040000  &6  &Secondary /\+ update image slot  \\
SWAP  &0x08060000  &7  &Temporary buffer for hardware image swap  \\
COMM  &0x08080000  &8  &Communication status word between BSW/\+\+ASW  \\
PROTECTED\+\_\+\+BSW\+\_\+\+STATE  &0x080\+A0000  &9  &Rollback counter + primary slot flag  \\
REPORT  &0x080\+C0000  &10  &Circular buffer of up to 5 BSW event reports  \\
\end{DoxyTable}


Write protection (OB\+\_\+\+WRP) is applied at the sector level and is reconfigured by the BSW as part of lifecycle management.

\DoxyHorRuler{0}
\hypertarget{md__t_e_s_t___s_u_i_t_e___d_e_s_c_r_i_p_t_i_o_n_autotoc_md27}{}\doxysection{\texorpdfstring{BSW Report Structure}{BSW Report Structure}}\label{md__t_e_s_t___s_u_i_t_e___d_e_s_c_r_i_p_t_i_o_n_autotoc_md27}
After each significant boot event, the BSW writes a {\ttfamily bsw\+\_\+report\+\_\+t} record (20 bytes) to the REPORT flash sector. Each report contains:\+


\begin{DoxyItemize}
\item {\bfseries{magic}} (4 bytes):\+ 0x\+BEEF0042 — marks a valid entry
\item {\bfseries{type}} (1 byte):\+ 0x01 = NOMINAL, 0x02 = UPDATE, 0x03 = SWAP
\item {\bfseries{outcome}} (1 byte):\+ 0 = success, non-\/zero = failure code
\item {\bfseries{primary\+\_\+slot}} (1 byte):\+ 0 = SLOT\+\_\+A, 1 = SLOT\+\_\+B (at time of report)
\item {\bfseries{rollback\+\_\+counter}} (4 bytes)
\item {\bfseries{primary\+\_\+version}} /\+ {\bfseries{secondary\+\_\+version}} (2 bytes each)
\item {\bfseries{step\+\_\+flags}} (4 bytes):\+ bitmask of completed steps within the operation
\end{DoxyItemize}

The test suite erases the REPORT sector before each test and verifies the report content after the BSW has run.
